# Kitten Knight Survivors

Прототип игры на выживание для браузера и Android. Кошечка автоматически атакует врагов, собирает кристаллы опыта и выбирает улучшения. Игрок проходит десять биомов, встречает в каждом уникального босса и получает активную суперспособность после победы. В каждом биоме есть два тематических противника; боссы появляются каждые пять минут, редкие сердца выпадают с шансом 5% и восстанавливают 25 HP. Игра доступна на русском, английском и украинском языках; язык выбирается перед запуском.

- `web/` — браузерная версия.
- `app/` — Android-приложение на Java и WebView.
- `app/src/main/assets/game/` — встроенная офлайн-версия.
- `tests/survivor-core.cjs` — проверки игровых механик.

Управление: на компьютере — WASD или стрелки, `Q` — суперспособность, `P` — пауза. На телефоне — динамический джойстик и кнопка способности.
