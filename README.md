# Кошечка-рыцарь — Лесная осада

Текущая веб-версия (`web/`) — арена на выживание в двух биомах: автоматические атаки, опыт, новые ледяная и молниевая способности, восемь типов обычных врагов и два босса. После Короля гоблинов открываются Хрустальные пещеры. Запуск: открыть `web/index.html`. Подробности — [SURVIVAL.md](SURVIVAL.md).

Android-приложение в `app/` пока содержит предыдущий прототип раннера. Его перенос на новый геймплей — следующий этап.

Проверка новой игровой логики: `node tests/survivor-core.cjs`.

# Kitten Knight Runner

Прототип 2D-раннера: кошечка в доспехах с мечом перепрыгивает кирпичные препятствия и сражается с гоблинами и драконами.

- `app/` — офлайн Android-приложение, Java + WebView, Android 8.0 и новее.
- `app/src/main/assets/game/` — игра, изображения и анимационные листы внутри приложения.
- `web/` — самостоятельный браузерный прототип. Открыть `web/index.html` в браузере.
- `README.md` — установка, сборка и ограничения Android-версии.

Управление: пробел/стрелка вверх — прыжок, X/K — атака, P — пауза. На телефоне доступны экранные кнопки. Три жизни, постепенно растущая скорость, локальное сохранение рекорда.

Графика создана с помощью генератора изображений. Анимационные листы остаются прототипными. APK прошёл проверку подписи, но запуск на Android-устройстве пока не проверен.


# Кошечка-рыцарь — Android 0.1.0

Установочный файл: kitten-knight-android.apk. Тестовый APK подписан; это сборка для ручного тестирования, не публикация в Google Play.

## Установка

1. Перенести APK на Android-телефон и открыть его.
2. Если Android запросит разрешение на установку из этого источника, разрешить его для приложения, которым открыт APK.
3. Установить «Кошечка-рыцарь» и запустить.

Требуется Android 8.0 или новее. Интернет игре не нужен. Все изображения и код находятся внутри приложения. Разрешения на интернет, камеру, микрофон и доступ к файлам не запрашиваются.

## Игра

Горизонтальная ориентация. Слева — прыжок, справа — атака. Нажатие на игровое поле также вызывает прыжок. Сверху — жизни, расстояние, очки и пауза. При сворачивании забег ставится на паузу. Рекорд сохраняется после окончания забега; удаление данных приложения удаляет рекорд. Кнопка «Назад» вызывает подтверждение выхода.

## Проверка

Java-код скомпилирован с Android SDK 35; ресурсы и локальные игровые файлы упакованы. Подписи APK v2 и v3 проверены apksigner. Проверено содержимое APK, минимальная версия Android и стартовая Activity. Синтаксис игрового JavaScript проверен.

На реальном телефоне и Android-эмуляторе приложение пока не запускалось. Нужно проверить запуск, сенсорные кнопки, паузу/сворачивание, возврат в игру и сохранение рекорда. Игровые кадры остаются прототипными.

## Исходники

Открыть папку проекта в Android Studio; требуются JDK 17, Android SDK 35 и Android Gradle Plugin 8.9.2. Проект не использует внешние библиотеки. При первой настройке Android Studio скачает необходимые инструменты.

Приложение отображает локальную Canvas-игру в Android WebView. Ресурсы перехватываются из assets через локальный HTTPS origin appassets.androidplatform.net; внешняя навигация блокируется. WebView не получает доступ к файловой системе и не содержит JavaScript-мостов.


## Сборка APK из командной строки

Установить JDK 17 и Android SDK 35, настроить путь к SDK через Android Studio или переменную ANDROID_HOME. Выполнить `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`). Результат: `app/build/outputs/apk/debug/app-debug.apk`. Gradle Wrapper включён в репозиторий и скачает Gradle 8.11.1 при первом запуске.
