# Кошечка-рыцарь — Лесная осада

Арена на выживание для браузера и Android. Кошечка автоматически атакует врагов, собирает кристаллы опыта и выбирает улучшения. После Короля гоблинов открываются Хрустальные пещеры; забег завершается битвой с Хрустальным стражем.

- `web/` — браузерная версия.
- `app/` — Android-приложение 0.2.0. Игра и рисунки находятся внутри APK, интернет не требуется.
- [SURVIVAL.md](SURVIVAL.md) — описание игры и управления.
- [android-launcher-icon.png](android-launcher-icon.png) — исходный рисунок иконки приложения.

## Android

Нужен Android 8.0 или новее. Игра открывается в горизонтальной ориентации. На телефоне двигайся сенсорным джойстиком; меч и способности атакуют автоматически. APK из этой ветки — тестовая сборка, не публикация в Google Play.

Для сборки открой проект в Android Studio с JDK 17 и Android SDK 35, затем запусти `./gradlew assembleDebug`. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
