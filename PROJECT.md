# Kitten Knight Runner

Прототип 2D-раннера: кошечка в доспехах с мечом перепрыгивает кирпичные препятствия и сражается с гоблинами и драконами.

- `app/` — офлайн Android-приложение, Java + WebView, Android 8.0 и новее.
- `app/src/main/assets/game/` — игра, изображения и анимационные листы внутри приложения.
- `web/` — самостоятельный браузерный прототип. Открыть `web/index.html` в браузере.
- `README.md` — установка, сборка и ограничения Android-версии.

Управление: пробел/стрелка вверх — прыжок, X/K — атака, P — пауза. На телефоне доступны экранные кнопки. Три жизни, постепенно растущая скорость, локальное сохранение рекорда.

Графика создана с помощью генератора изображений. Анимационные листы остаются прототипными. APK прошёл проверку подписи, но запуск на Android-устройстве пока не проверен.
